## Gotchas
1. **Claude Code refuses to skip permissions as root.** The OS agent runs as the normal user with sudo.
2. **Codex ignores user hooks until they're trusted interactively.** Ship snapshot hooks as managed hooks (`requirements.toml`) or they will silently not run.
3. **There is no universal skills path.** `~/.agents/skills` covers Codex, Gemini CLI, opencode, OpenClaw, pi and Cursor. Claude Code also needs `~/.claude/skills`, and `agy` needs `~/.gemini/config/skills`.
4. **There is no universal user-level AGENTS.md.** Claude Code needs an `@import` in CLAUDE.md, Gemini CLI needs `context.fileName`, Cursor has no file, and OpenClaw reads only its workspace.
5. **opencode v2 broke the v1 config formats** (MCP, permissions, plugins). Ignore older blog posts.
6. **Redistribution:** Claude Code, Cursor and `agy` must not be bundled in the ISO. Install them at onboarding from the official installer or repo.
